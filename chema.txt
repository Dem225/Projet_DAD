Pour ajouter UN site
bash
python main.py ajouter --site AC777 --gateway AC622 --tech 3G --nom "NOM DU SITE"
--site : l'identifiant du nouveau site (ex: AC777)
--gateway : le routeur auquel il se rattache (doit exister dans Gateway.xlsx, ex: AC622)
--tech : une ou plusieurs technologies, séparées par des espaces (ex: --tech 2G 3G 5G)
--nom : optionnel, le nom du site
Pour ajouter PLUSIEURS sites d'un coup

Prépare un Excel avec les colonnes Site ID, Router Gateway, Technology (une ligne par site+techno), puis :

bash
python main.py import nouveaux_sites.xlsx
Si tu ne connais pas les valeurs possibles (Router Gateway, Technology)
